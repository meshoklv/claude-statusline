# Changelog

## v0.1.0 — first public release

- Segments: model, context bar, 5-hour limit with reset timer and burn-rate flame, weekly limit, effort/thinking/fast mode, session tokens, session cost, directory, git branch, MCP count, session uptime.
- Order, selection, colours, bar width, separator, thresholds and labels via `~/.config/claude-statusline/config.json`.
- English and Russian labels.
- `install.sh` with settings backup, refuse-to-clobber, `--uninstall` that restores your previous status line.
- Zero dependencies, no network, graceful on missing data.
